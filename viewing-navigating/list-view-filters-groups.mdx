List View is where the work lives. Every Pin you've created, been assigned, or are following sits here in one scrollable list with the key details at a glance — title, location, status, assignee, priority, due date, and recurring status. The Map shows you where work is happening; List View is where you actually manage it.

Tap any Pin to open its full detail view.

## Scope Views

At the top of both List and Map views, toggle between three scopes:

| Scope | What It Shows |
| --- | --- |
| **Team Pins** | All active Pins across your department. _(Managers and Users only.)_ |
| **My Pins** | Pins currently assigned directly to you. |
| **Following** | All Pins you are following — Pins you created or were added to as a follower. |

## Within Your List

Pins are listed in chronological order by default. On the web app, you can also sort the list by other columns to surface what you need first — including **scheduled date and time** for Pins with a start date.

- **Recurring Pins** — identified by the recurring arrows icon next to the title. They appear alongside your regular Pins and can be filtered separately. Tapping a recurring Pin opens that specific instance.
- **Scheduled Pins** — any Pin with a **Start Date** set displays a **Scheduled** badge showing the date and time work is meant to begin. Scheduled Pins are still visible in the assignee's feed immediately; the badge is informational.
- **Groups** — folders that organize Pins together. Groups appear inline in your list. Tap a Group to see all the Pins inside it.

## Filters & Search

Tap the filter icon to narrow your view by:

- **Status** — To Do, In Progress, Blocked, or Cancelled
- **Priority** — show only Pins marked as Priority
- **Scheduled** — show only Pins with a start date set
- **Date range** — filter by created, start, or due date
- **Recurring frequency** — show only recurring Pins, or filter by cadence (Hourly, Daily, Weekly, Biweekly, Monthly, Every 3 Months, Every 6 Months, Yearly)
- **Groups** — show Pins inside a specific Group

Filters stack — for example, all Priority, overdue Pins in the Leaks group.

The search bar at the top of List View lets you quickly find any Pin by title.

The same scope toggles are also available on Map View.

## Bulk Actions on Pins (Web)

On the web app, you can select multiple Pins from the list view (or from within a group) using the checkbox next to each Pin. A **select all** option is also available. Once you have a selection, an **Actions** menu appears with:

- **Assign** to a user
- **Change status**
- **Add to** or **remove from** a group
- **Delete** (only for users whose role allows Pin deletion)

Any user can use bulk actions, but only for actions their role has access to. Pins from multiple departments can be selected in the same bulk action. Standard follower and notification rules apply — the person taking the action becomes a follower, and assignees receive their standard notifications, applied across every selected Pin.

Bulk actions are available on **web only**.

## Exporting the List

The full list view can be exported to a spreadsheet using the **Export** button at the top right. The export includes all relevant fields for every Pin in the current view — respecting any filters applied.

The same **Export** button is available on every list view page across PIN — Pins, Recurring Pins, Groups, Projects, Incidents, Equipment, Inventory, Locations, Documents, Vendors, Procedures, Users, Departments, and more.

## Groups

Groups are folders. They let you bundle similar Pins — or any Pins you want to keep together — into one place to make managing them simpler.

Common ways teams use Groups:

- **Recurring scheduled work** — Daily Opening Checklists, Quarterly HVAC PMs
- **A category of issues you want to track together** — Leaks, Light Bulb Replacements
- **Work tied to a specific area or asset type** — Parking Garage Pins, Escalator Issues

### Creating a Group

Any user can create a Group. From the Groups page, tap **\+ Create Group**, give it a name, and save.

### Adding Pins to a Group

Pins can be added to a Group at the time of creation, or at any time after.

- **When creating a Pin** — tap the Group field on the create screen and select the Group you want to add it to.
- **From an existing Pin** — open the Pin, tap the three-dot (⋯) menu, and select **Add to Group**.
- **From a recurring series** — open any recurring Pin instance, tap the purple marker at the top to open the options tab, and add the series to a Group. Every future instance will be added automatically.

### Managing a Group

Tap into any Group to see all the Pins inside it and manage them together.

Once a Pin is added to a Group, a chip appears at the top of the Pin's detail page showing which Group it belongs to.

A Pin can be removed from a Group at any time — open the Pin, tap the three-dot (⋯) menu, and select **Manage Group**. You can remove any Pin from a group

## Other Places to View Pins

Pins also appear in other parts of the platform:

- **Equipment pages** — any Pin linked to a piece of equipment can be viewed from that equipment's record, including active and completed history.
- **Location pages** — any Pin created at a specific location can be viewed from that location's page.
- **Projects** — if you are a follower on a project, you can view all Pins linked to that project from within the Projects module.
