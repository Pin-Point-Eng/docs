# Welcome to Pin Help

Pin helps teams turn work, issues, requests, and incidents into trackable items called Pins. Each Pin can be tied to a place on the map, assigned to the right team, discussed in context, and followed until the work is complete.

Use this help center when you need a quick reminder on how to:

- Create a Pin
- Find work on the map
- Update or complete a Pin
- Use chat with your team
- Manage users, teams, equipment, inventory, and locations
- Review activity and analytics

## Best place to start

If you are new to Pin, start with [What Pin is for](/getting-started/overview), then read [Finding your way around](/getting-started/navigation).

If you already know what you need, use the search bar or ask the help assistant a question in normal language, such as:

- How do I create a Pin?
- Where do I see Pins near me?
- How do I add a teammate?
- Why can I not see a setting?
