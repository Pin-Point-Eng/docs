# Changelog

What's new in Pin, newest first. Entries tagged **Internal** are engineering, support, and operations notes for the Pin team.

<Update label="October 2, 2026" tags={["Pins","Incidents","Media"]} description="Redesigned detail pages">
  Every record page on web has a cleaner layout that's faster to work in.

  - Edit titles, descriptions, and details in place — no edit dialog
  - The next status action sits in the header
  - The header collapses as you scroll, keeping tabs in reach
  - Create anything related from the record's **Create** menu
  - Incident reports open and edit right on the incident

  ### Improvements

  - Recurring series can have a due time
  - "This and all future" due date edits now apply to the series
  - Every create page shares one layout
  - Create menu grouped into Work and Assets
  - Media viewer: arrow keys, download, zoom, and PDF preview
  - Media viewer sizes to the photo, video, or PDF
  - Uploads show progress per file with retry
  - Drop files anywhere or paste from the clipboard
  - iPhone photos display as profile pictures
  - "Discard changes?" before leaving an unsaved form
  - Open list rows in a new tab
  - Mobile shows when you're offline
  - Mobile keeps your Pin if creating it fails

  ### Fixes

  - Routine rounds like fire watches are no longer flagged as duplicates
  - Mobile chats clear their unread badge once opened
  - Pinch to zoom works on Android
  - The Pins tab keeps your chosen scope on Android
  - Saving inventory no longer resets stock to 0
  - Cloning a recurring series copies its attachments
  - Android opens PDFs in your PDF app
</Update>

<Update label="September 28, 2026" tags={["Pins","Notifications","Map"]} description="Translate any Pin">
  Read any Pin in your own language. [Learn more](/pins/managing-a-pin#pin-translation)

  - Tap **Translate** on a Pin and pick a language
  - Translates the title, description, checklist, form fields, and notes
  - Tap **Show original** to switch back
  - Works on web and mobile for anyone who can see the Pin

  ### Improvements

  - Team email rules can fire when a Pin goes overdue
  - Team email rules can match specific assignees
  - Cloning a Pin can copy its attachments
  - Search the web map for any location
  - Web map previews show photos, documents, and tappable emergency contacts
  - Each browser tab can stay on a different facility
  - Redesigned create menu on mobile
  - Pin PDFs show times in your venue's timezone
  - Canceled duplicates get their own badge on web
  - Refreshed top bar, notifications, settings, and profile pages on web
  - SSO can be required for specific email domains
</Update>

<Update label="September 3, 2026" tags={["Admin","Notifications"]} description="Team email notifications">
  Email anyone about Pin activity — vendors, contractors, or leadership — without a Pin account. [Learn more](/admin/team-email-notifications)

  - Trigger on created, in progress, blocked, completed, cancelled, or reopened
  - Narrow by department, location, equipment, or inventory
  - Send to any To and CC addresses
  - Optionally attach a PDF of the Pin with photos
  - Set up under **Settings › Team email notifications**
</Update>

<Update label="August 27, 2026" tags={["AI","Pins","Projects","Map","Equipment"]} description="Safety risk and duplicate detection">
  Pin's AI now checks every new Pin for hazards and repeats. [Learn more](/pins/managing-a-pin#ai-duplicate-pin-detection)

  - Flags urgent hazards like exposed wiring or spills from the text and photo
  - Mark it high priority in one tap, or dismiss
  - Spots likely duplicates of open Pins and explains the match
  - Keep the Pin or cancel the duplicate

  ### New

  - Clone any Pin from its **⋯** menu
  - Project categories get comment threads and a project log
  - Project chats appear in the Chat module
  - Click anything on the web map for a quick preview
  - Print QR codes for equipment and inventory; scan them on mobile
  - Export any list to CSV
  - Daily summary email for managers

  ### Improvements

  - AI procedure creation reads PDFs, Word, spreadsheets, CSV, and images
  - New Pin filters: potential duplicates, linked equipment, linked inventory, attachments
  - Link equipment to a vendor
  - Medical and Slip-and-Fall incident filters
  - Chat's Updates mode stays on until you turn it off
  - Sort Pins in a group by due date, creation date, or title
  - Search everything from one place on mobile
  - Photos and mentions in project chats
  - Mobile asks before sending a photo to AI
</Update>
