# Changelog

Follow this page for major Pin updates, new workflows, and important changes that affect how your team uses the app.

<Update label="May 29, 2026" tags={["Mobile","Inventory"]} description="Use Inventory quantity entry">
  The Use Inventory dialog now prompts for a quantity and optional notes when consuming inventory from a Pin, making it easier to track exact amounts used.
</Update>

<Update label="May 29, 2026" tags={["Web","Pins"]} description="Create a Pin from a checklist item on web">
  You can now create a new Pin directly from a checklist item in the web app.

  If you find an issue while working through a checklist, use the create-Pin action on the checklist item to spin up a separate Pin for the issue without leaving the checklist. The new Pin can be assigned, prioritized, and tracked on its own while the original checklist stays intact.
</Update>

<Update label="May 8, 2026" tags={["Help Center"]} description="Help center launched">
  The Pin help center is now live at [docs.pin.works](https://docs.pin.works).

  The first version includes guides for creating Pins, managing work, using the map, using chat, managing users and teams, working with equipment, inventory, and locations, and reviewing analytics.
</Update>
