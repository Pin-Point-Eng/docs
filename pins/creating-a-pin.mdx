---

Anyone can create a Pin at any time — for your own department, another department, or a specific individual. When a Pin is assigned to a department, it goes to that department's managers to route to the right person.

To create a Pin, tap the **\+** button. You can fill in the Pin's details manually, or use Snap-to-Pin to let AI do the work for you.

<Tip>
  Need work to repeat on a schedule — daily checklists, weekly inspections, monthly PMs? Use the **\+ Create a recurring Pin instead** option from the create screen. See [Recurring Pins & Checklists](/pins/recurring-pins-checklists) for full details.
</Tip>

## Snap-to-Pin ✨

Snap-to-Pin is PIN's built-in AI feature that makes creating a Pin even faster. Tap the AI sparkle icon ✨ at the top of the create screen and give it one of three inputs:

- **Take a photo** — great for issues (a spill, a broken fixture, damaged equipment).
- **Upload a photo** — pull an image from your device.
- **Upload a file** — a PDF, doc, or image of a checklist (like a printed inspection sheet).

PIN's AI reads the input and generates the right Pin automatically:

- If the input is a photo of an **issue**, it fills in the title, description, and suggested department for routing.
- If the input is a photo or file of a **checklist**, it builds a full checklist inside the Pin with the items pulled directly from the source.

The suggested department is informed by each team's **Description** in Organization Settings — the more specific the description, the better the routing.

Snap-to-Pin is available on both the mobile app and the web app.

<Warning>
  Always double-check the AI-generated information for accuracy before submitting.
</Warning>

## Safety Risk Detection

PIN's AI evaluates every Pin as it's being created. If the title, description, or a Snap-to-Pin photo indicates an urgent safety risk — such as exposed wiring, a spill, or a hazard — a **Safety Risk Detected** banner appears on the create screen with a short explanation of the risk.

You have two options:

- **Mark as High Priority** — sets the Pin to high priority so the assignee treats it urgently.
- **Dismiss** — clears the banner.

If you dismiss or ignore the banner, the Pin is not automatically marked as priority. Available on both mobile and web.

## Manually Input: What to Fill In

- **Title** (required). Be specific — a clear title helps the right team act faster.
- **Description** (optional but recommended). Include any detail that helps the team understand the issue.
- **Assignee** (required). Choose a department or a specific individual.
- **Media** (optional). A photo or video helps the receiving team understand the issue immediately.

## Optional Details

| Field | What It Does |
| --- | --- |
| Followers | Add users who should have visibility and receive updates. The creator and assignee are added automatically. |
| Start Date | Schedule when work on the Pin is meant to begin. The Pin is still created and visible immediately — the start date is informational, not a delay. Pins with a start date show a **Scheduled** badge with the date and time. |
| Due Date | Set a deadline for when the task needs to be completed. |
| Priority | Flag the Pin so the assignee knows to treat it urgently. |
| Link Equipment | Attach this Pin to one or more pieces of equipment to build maintenance history. See [Linking equipment and inventory](#linking-equipment-and-inventory) below. |
| Link Inventory | Attach one or more inventory items to the Pin and log how much was used. See [Linking equipment and inventory](#linking-equipment-and-inventory) below. |
| Checklist | Add step-by-step items that need to be completed as part of the task. Choose **New checklist** to build one from scratch, or **Use template** to pull from a saved [procedure](/modules/procedures). Long checklists can be organized into collapsible sections. |
| Group | Add the Pin to a group — a folder for organizing similar Pins together. |
| Project | Add the Pin to a project. When you select a project, you can also select which **category** within that project the Pin belongs to, directly from the create screen. |
| Tags | Short keyword labels — like `Leak`, `VIP`, or `Safety` — that make Pins easier to categorize, search, and filter later. Add as many as needed. |
| Private | Make the Pin visible only to you and the assignee. |

<Info>
  Start Date does not delay the Pin from appearing in the assignee's feed and does not trigger a notification when the date arrives. It is informational. Recurring Pins use **First Occurrence** instead — start date does not apply there.
</Info>

## Linking Equipment and Inventory

A Pin can be linked to any number of equipment items and any number of inventory items. Both are linked directly from the Pin's detail page.

### Equipment

Link one or more equipment items to the Pin. When multiple equipment items are linked, choose:

- **Which equipment items have their condition updated** when the Pin is completed.
- **Which linked equipment's location the Pin inherits.**

The Pin appears in the full Pin history of every equipment item it is linked to.

### Inventory

Link one or more inventory items to the Pin the same way equipment is linked. When linking an inventory item, you can log the quantity used at that time, or update the quantity later from the inventory item's detail page.

- Any quantity logged on the Pin automatically reduces the on-hand quantity in the [Inventory module](/modules/inventory).
- If the on-hand quantity drops below the minimum threshold as a result, a restock Pin is automatically created.
- Inventory usage is written to the inventory item's history, giving a running record of where and when that item was used.

Any user with permission to edit inventory can log inventory used on a Pin.

## Groups

Groups are folders that organize similar Pins together. Any user can create a group, and groups are visible across all departments. To create a group, navigate to the Groups section within the Pins module and tap the create button. Only a name is required.

## Private Pins

Toggling a Pin to Private makes it visible only to you and the person it is assigned to — no one else on the platform can see it. Private Pins are ideal for logging personal tasks, reminders, or notes that you need to track for yourself but do not need to share with your team.

## Setting the Location

Every Pin needs a location on the map. Tap **Select Location** and either use the blue dot while on property to place the Pin at your exact current position, search for a space by name, or let it auto-populate from a linked equipment item. If multiple equipment items are linked, you choose which one's location the Pin inherits.

If you select a location with registered equipment, PIN will ask if you want to link it and optionally update its condition.

## After the Pin Is Created

Once the Pin is submitted:

- **The right people are notified.** If the Pin was assigned to a department, the department managers are notified so they can route it. If it was assigned directly to a user, that user is notified.
- **The Pin appears on the property map** at the location it was created, alongside every other active Pin and asset.
- **It's now live in the system** — the assignee, followers, and managers can update its status, communicate inside it, and track it through to completion.

<Info>
  Admins can also set up [team email notification rules](/admin/team-email-notifications) that automatically send an email to anyone — inside or outside the organization — when Pins matching specific criteria are created. Useful for looping in vendors, contractors, tenants, or leadership without giving them a PIN account.
</Info>
