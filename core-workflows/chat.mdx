# Use Chat

Chat keeps work conversations close to the work itself. Instead of switching between separate messaging tools, teams can talk in the context of a Pin, group, or direct conversation.

## Where chat appears

Chat may appear in:

- The main **Chat** section
- A Pin's chat tab
- Team or group conversations
- Direct conversations, depending on your workspace setup

## Use chat on a Pin

Use Pin chat when the message is about that specific Pin.

Examples:

- Asking for more detail
- Sharing an update from the location
- Confirming that work is complete
- Mentioning another teammate
- Adding context for the next person who opens the Pin

## Keep messages useful

Use clear, specific messages. If the conversation changes the work, also update the Pin status, assignee, checklist, or notes so the official Pin details stay accurate.

## If you miss messages

Check **Notifications** and **Chat** for unread activity. If you are not receiving expected messages, ask an administrator to confirm that you are included in the right team, conversation, or Pin followers.
