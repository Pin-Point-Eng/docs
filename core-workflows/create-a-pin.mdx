# Create a Pin

Create a Pin when something needs attention, follow-up, assignment, or tracking.

## Create from the sidebar

1. Select **Create** in the sidebar.
2. Choose **Pin**.
3. Add a clear title.
4. Add the location where the work is needed.
5. Add the team, assignee, due date, details, checklist items, photos, equipment, or inventory if they apply.
6. Submit the Pin.

## Create from the map

Use the map when the exact location matters.

1. Open **Map**.
2. Choose the create Pin action.
3. Select the location on the map.
4. Fill in the Pin details.
5. Submit the Pin.

## Create a recurring Pin

Use recurring Pins for work that happens on a schedule, such as daily checks, weekly inspections, or repeated maintenance.

1. Select **Create** in the sidebar.
2. Choose **Recurring Pin**.
3. Add the Pin details.
4. Set the schedule.
5. Save the recurring Pin.

## Tips for better Pins

Use a short, specific title. A title like "Water leak near west hallway" is easier to act on than "Issue".

Add the location whenever possible. Location is one of the fastest ways for teammates to understand where the work is.

Attach photos or files when they help explain the issue.

Assign the Pin to the right person or team if you know who should own it.
