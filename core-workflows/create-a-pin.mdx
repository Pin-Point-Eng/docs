# Create a Pin

Create a Pin when something needs attention, follow-up, assignment, or tracking.

## Create from the sidebar

1. Select **Create** in the sidebar.
2. Choose **Pin**.
3. Add a clear title.
4. Add the location where the work is needed.
5. Add the team, assignee, due date, details, checklist items, photos, equipment, or inventory if they apply.
6. Submit the Pin.

## Create from anywhere

In the mobile app, you can use the **+** button to create a Pin from wherever you are working. Add the details manually, or use AI Snap-to-Pin if it is available in your workspace.

With AI Snap-to-Pin, take a photo and let Pin help fill in the relevant information. Review the details before submitting so the location, title, description, team, and attachments are accurate.

## Create from the map

Use the map when the exact location matters.

1. Open **Map**.
2. Choose the create Pin action.
3. Select the location on the map.
4. Fill in the Pin details.
5. Submit the Pin.

## Create a recurring Pin

Use recurring Pins for work that happens on a schedule, such as daily checks, weekly inspections, or repeated maintenance.

1. Select **Create** in the sidebar.
2. Choose **Recurring Pin**.
3. Add the Pin details.
4. Set the schedule.
5. Save the recurring Pin.

## What happens after a Pin is created

1. Something needs attention on the property.
2. A Pin is created, assigned, and placed on the map.
3. A manager or owner is notified and can add details, set priority, or assign a team member.
4. The assigned user receives the Pin and starts the work.
5. Updates, photos, files, and messages stay inside the Pin.
6. When the work is done, the Pin is marked complete and remains searchable for future reference.

## Tips for better Pins

Use a short, specific title. A title like "Water leak near west hallway" is easier to act on than "Issue".

Add the location whenever possible. Location is one of the fastest ways for teammates to understand where the work is.

Attach photos or files when they help explain the issue.

Assign the Pin to the right person or team if you know who should own it.

Choose the location and related equipment when they apply. This makes the Pin easier to find on the map and easier to understand later.
