# Use the Map

The map helps teams understand where work is happening. It is useful when location matters more than a list view.

![Pin map](/images/map.png)

## What you can do from the map

Use the map to:

- View Pins by location
- Create a Pin at a specific place
- See nearby work
- Find equipment or location-related work, depending on your workspace setup
- Understand active work across a facility

## Create a Pin from the map

1. Open **Map**.
2. Choose **Create Pin**.
3. Select the location.
4. Add the Pin details.
5. Submit the Pin.

## When to use the map instead of the list

Use the map when:

- The exact place matters
- You are planning a route or walkthrough
- You need to see several nearby Pins together
- You are checking activity in a specific area

Use the Pin list when you need to sort, filter, or compare work by status, assignee, team, or due date.
