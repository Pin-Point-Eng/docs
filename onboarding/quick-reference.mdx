# Quick Reference

Use this page when you know what you need to do and just need a reminder.

| Task | How |
| --- | --- |
| Create a Pin manually | Use **Create** or **\+**, fill in title, assignee, and location, then submit. |
| Create a Pin with Snap-to-Pin | Use **Create** or **\+**, choose the AI sparkle action, take or upload a photo (or upload a file), review the generated fields, set the location, then submit. |
| Generate a checklist with Snap-to-Pin | On the create screen, tap the AI sparkle icon, take a photo or upload a file of a checklist, and PIN generates the checklist items inside the Pin. |
| Set a start date on a Pin | When creating a Pin, open the Start Date field and pick a date and time. Edit or remove later from the Pin actions menu. |
| Filter Pins by scheduled date | In the Pins list, open filters and turn on **Scheduled** to show only Pins with a start date. Sort by scheduled date on web. |
| Link multiple equipment to a Pin | Open the Pin's detail page, add each equipment item, then choose which items get condition updates and which one's location the Pin inherits. |
| Link inventory to a Pin | Open the Pin's detail page, add one or more inventory items, and log the quantity used at link time or later from the inventory item's detail page. |
| Log inventory used on a Pin | Open the Pin, add or open the linked inventory item, enter the quantity used, and save. On-hand quantity updates automatically. |
| Bulk-action multiple Pins (web only) | On the web app, use the checkboxes in the Pins list (or **Select All**), then choose assign, change status, add/remove from group, or delete. |
| View a project on the Timeline (web only) | Open a project on the web app and switch to the **Timeline** tab. |
| Save a checklist as a procedure | Open the Pin's checklist and tap **Save as Procedure**. It becomes available in the Procedures library for anyone to reuse. |
| Find your Pins | Open **Pins**, then switch between Team Pins, My Pins, and Following. |
| Search for a Pin | Use the search bar or filters in the Pins list. |
| View work by location | Open **Map** and use the current view or filters. |
| Update Pin status | Open the Pin, choose the status, and select the correct state. |
| Mark work as started | Open the Pin and set the status to **In Progress**. |
| Mark a Pin as blocked | Set status to **Blocked** and leave a chat message explaining what is blocking the work. |
| Mark a Pin as priority | Open the Pin actions menu and choose the priority action, if available. |
| Add a follower | Add followers from the Info tab or @ mention someone in Pin Chat. |
| Make a Pin private | Turn on Private during creation or use the Pin actions menu, if available. |
| Complete a Pin | Open the Pin, mark it complete, add notes or photos if required, then confirm. |
| Convert a Pin to an incident | Open the Pin actions menu and choose Convert to Incident, if available. |
| Work a recurring checklist | Open the recurring Pin, complete checklist items, create new Pins for issues found, then mark the instance complete. |
| Apply a procedure template to a Pin | When creating a Pin or Recurring Pin, in the Checklist field choose **Use template** and select a saved procedure. |
| Create a procedure template | Open **Library → Procedures** (web) or **More → Procedures** (mobile), tap **\+ New Procedure Template**, add items, and save. |
| View recurring series options | Open a recurring Pin and use the series or options area. |
| Post an update in chat | Open the Pin chat, choose the update action if available, write the update, and send. |
| Send a direct message | Open **Chat**, compose a direct message, choose a user, and send. |
| Enable Do Not Disturb | Open profile settings and turn on Do Not Disturb, if available. |
| View notifications | Open **Notifications** or check the Overview dashboard. |
| Create a vendor | Open **Vendors**, tap **\+ New Vendor**, add name, type, and contacts (mark one Primary), then save. |
| Link inventory to a vendor | Open the inventory item, edit the **Vendor** field, and select the vendor. |
| Find inventory from a vendor | Open the vendor profile and check the **Inventory** section. |
| Find equipment | Open **Equipment**, then search or filter by type. |
| Update equipment condition | Open the equipment record and change the condition. |
| Create a Pin from equipment | Open the equipment record and choose the create Pin action. |
| Find a location | Open **Locations** and search by name. |
| Create a Pin from a location | Open the location page and choose **\+ Pin** or the create Pin action. |
| View a project | Open **Projects** and select a project you follow. |
| Create an incident | Open **Incidents**, choose create, fill in the incident details, and submit. |
| Submit an external request | Use your venue's request link or QR code, fill in the form, and optionally opt in to email updates before submitting. |
