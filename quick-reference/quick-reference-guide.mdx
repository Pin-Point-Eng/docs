A quick lookup for the most common tasks across the PIN platform.

## Pins

| Task | How |
|------|-----|
| Create a Pin manually | Tap "+" → Title → Assignee → Location → Create Pin |
| Create a Pin with AI | Tap "+" → Sparkle icon ✨ → Take a photo → Review fields → Location → Create Pin |
| Find your Pins | Pins → Toggle Team / My Pins / Following → Search bar or filters |
| Update Pin status | Open Pin → Tap status at top → To Do / In Progress / Blocked / Cancelled |
| Mark work as started | Open Pin → Tap status → Select In Progress |
| Mark a Pin as priority | Open Pin → Tap ⋯ menu → Mark Priority |
| Add a follower | Open Pin → Info tab → Followers → Add user. Or @ mention in Pin Chat. |
| Make a Pin private | When creating → Toggle Private on. Or open Pin → Tap ⋯ menu → Make Private. |
| Complete a Pin | Open Pin → Tap "Mark Complete" → Add notes → Confirm |
| Convert a Pin to an incident | Open Pin → Tap ⋯ menu → Convert to Incident |

## Recurring Pins

| Task | How |
|------|-----|
| Work a recurring checklist | Open Recurring Pin → Work through items → Long press any issue to create a Pin → Mark complete |
| Flag an issue from a checklist | Long press/hold the checklist item → New Pin created and routed automatically |
| View recurring series options | Open Recurring Pin → Tap the purple marker at the top → Options tab |

## Chat

| Task | How |
|------|-----|
| Post an update in chat | Open Pin → Chat tab → Tap + → Select Update → Type message → Send |
| Send a direct message | Chat → Compose icon → Direct → Choose a user |

## Notifications & Settings

| Task | How |
|------|-----|
| View all notifications | Notifications in left nav (web) or Overview dashboard (mobile) |
| Enable Do Not Disturb | Profile settings → Do Not Disturb → Toggle on |

## Equipment

| Task | How |
|------|-----|
| Find equipment | Equipment → Search or filter by type → Tap to open the record |
| Update equipment condition | Open Equipment record → Tap condition → Select Excellent / Good / Poor / Out of Service |
| Create a Pin from equipment | Open Equipment record → Tap "Create Pin" → Fill in details → Submit |

## Locations

| Task | How |
|------|-----|
| Find a location | Locations → Search by name → Tap to open |
| Create a Pin from a location | Open Location page → Tap "+ Pin" → Fill in details → Submit |

## Projects & Incidents

| Task | How |
|------|-----|
| View a project | Projects → Tap the project (followers only) |
| Create an incident | Incidents → Tap "+" → Fill in title, type, assignee, followers, location → Submit |

## Tenant Portal

| Task | How |
|------|-----|
| Submit a tenant request | Visit your venue portal link (provided by your admin) → Fill in the form → Submit |
