description: "Understand PIN's default roles, recommended additional roles, situational roles, and custom permissions."
---

PIN uses a role-based access system. A user's role determines what they can see and do across the platform.

Every new PIN account comes with three default roles that are pre-loaded and ready to use. Admins can assign these immediately or create additional custom roles to match the venue's operating model.

## Default roles

These roles are pre-loaded into every PIN account and cannot be removed.

| Role | Description |
| --- | --- |
| Admin | Full access to everything in PIN, including settings, users, teams, all modules, and all data. This role is locked and cannot be modified or deleted. Assign it only to venue administrators. |
| Manager | Full visibility across their department. Managers receive all Pins assigned to their department, route and reassign work, oversee operations, access department chats, view analytics, and manage equipment and inventory. Managers can also view Pins, equipment, and inventory across other departments when needed. |
| User | Standard role for frontline staff. Users can create Pins for any department, manage and complete assigned work, communicate within tasks and with other users, and view their department's Pins, equipment, and inventory. Users receive notifications for Pins assigned to them or Pins they follow. |

## Recommended additional roles

PIN recommends creating these roles for common large-venue scenarios. They are not pre-loaded; create them from **Settings \> Roles & Permissions \> Create Role**.

| Role | When to use |
| --- | --- |
| User — Limited | For field users who should only see Pins directly assigned to them or Pins where they are a follower. This role is ideal for frontline staff who do not need to see the full department queue. Equipment and Inventory access is the same as the standard User role. |
| Manager — Team Only | For managers who should be locked to their own department's Pins, Equipment, and Inventory with no ability to view other departments. This is useful for third-party contractors, external vendors, or teams that should not have cross-property visibility. |

## Situational roles

Create these roles only when they match how your venue operates.

### Location Manager

Location Managers are responsible for specific physical areas or zones across the property. They are automatically added as followers on every Pin created within their assigned locations, regardless of which department the Pin belongs to.

This gives them real-time visibility into all operational activity in their area of responsibility.

### Incident Manager

Incident Managers oversee active security, safety, and medical incidents. They can see all active incidents and associated reports regardless of assignment or follower status, with full access to historical incident records after closure.

<Warning>
  Only Incident Managers can officially close incidents within the platform.
</Warning>

## Custom roles

If the default and recommended roles do not match your needs, admins can create custom roles from scratch.

Go to **Settings \> Roles & Permissions \> Create Role**, then configure each permission by turning it on or off.

| Permission area | What it controls |
| --- | --- |
| Scope | Whether the user sees all teams, assigned teams, or only their own work. |
| Team Pin Notifications | Whether the user receives notifications for all Pins assigned to their department. |
| Pins | Create and edit Pins, reassign Pins, and delete Pins. |
| Equipment | View, create and edit, or delete equipment. |
| Inventory | View, create and edit, or delete inventory. |
| Incidents | View all incidents, create and edit incidents, and close incidents. |
| Projects | View all projects, create projects, edit project details and contents, and delete projects. Without "View All", users only see projects they follow. |
| Users | Create and edit users or delete users. |
| Departments | Create and edit departments or delete departments. |
| Locations | Edit location details. |
| Analytics | View analytics. |
| Administration | Send broadcasts and manage administrative settings. |

<Tip>
  Start with PIN's three default roles if you are unsure. You can always create additional roles later as operational needs become clearer.
</Tip>
