Organization Settings control venue-wide behaviors in PIN, including how tenant requests are routed, whether dispatch calling is enabled, and who can broadcast messages to the whole team.

These settings are not required before going live. Configure them at your own pace after teams have started using PIN.

Go to **Settings > Organization Settings** in the PIN web app.

## Tenant Portal routing

The Tenant Portal lets anyone submit a request into PIN without a PIN account, using a public link or QR code.

As an admin, configure how those submissions are routed:

- **Triage first** - send all tenant submissions to one department for review and routing.
- **Direct routing** - send tenant submissions directly to the intended department.

The portal link is generated automatically and can be shared through email, signage, tenant handbooks, or back-of-house posters.

QR codes are created on demand from the **Pin QR Generator**, available from the create menu on the web app sidebar and from each location's page in the Locations module. Every QR code is signed to a specific team and an optional location, so submissions route to the correct group automatically — there is no longer a single venue-wide default team for QR submissions.

## Dispatch calling

Dispatch calling lets users call a designated dispatch number from inside the PIN app. This is useful for security teams and operations centers that rely on a direct phone or radio line.

Admins can:

- Enable or disable dispatch calling
- Set the phone number users call when they tap the dispatch button

## Broadcast messages

Broadcasts let designated users send a chat message to every user on the platform at the same time.

Use broadcasts for:

- Product or process updates
- Important operational announcements
- Venue-wide communications

Broadcast permissions are controlled from [Roles & Permissions](/getting-started/roles-permissions). Users need the appropriate broadcast permission before they can send a broadcast.
