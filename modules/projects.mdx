A Project is how PIN tracks any initiative that spans multiple tasks, Pins, departments, and timelines — all in one place. Every department and user involved works out of the same project, with full visibility into each Pin's current status, what has been completed, and what is still outstanding.

Common examples include tenant store openings, renovations, seasonal changeovers, compliance initiatives, and any multi-step operational effort requiring coordinated tracking.

## Who Can See a Project

By default, projects are **follower-based** — users only see projects they have been added to as followers. Roles with the **Projects — View All** permission see every project in the venue.

<Info>
  If you are assigned a Pin inside a project but are not a project follower and do not have View All, you will see that Pin in your regular Pins list — but not the project itself. Your active projects can be found on the Overview screen as well as in the Projects module.
</Info>

Creating, editing, and deleting projects are controlled by the **Projects** permissions on each role. See [Roles & Permissions](/getting-started/roles-permissions) for the full breakdown.

## What's on a Project Page

Each project has a title, description, due date, and a **live progress bar** that updates automatically as Pins inside it are completed.

| Tab | What It Contains |
| --- | --- |
| **Pins** | All Pins linked to the project, organized into categories. Each Pin shows its assignee, due date, location, and completion status. |
| **Timeline** | A Gantt-style view of every Pin in the project, plotted by start and due date. See [Timeline view](#timeline-view) below. **Web only.** |
| **Documents** | All documents associated with the project — files uploaded directly plus attachments from linked Pins surfaced here automatically. Documents uploaded to a project are visible to anyone following the project. |
| **Chat** | The project's group chat. See [Project Chat](#project-chat) below. |
| **Followers** | Everyone with access to the project. Add or remove followers here. |

A **Logs** button also sits at the top right of every project page on the web app. On mobile, the log is accessible from the three-dot menu on the project. See [Project Log](#project-log) below.

## Project Categories

Pins are grouped into Categories inside every project — each representing a different workstream or area of the initiative. Categories are folders within the project; you can have as many as needed and as many Pins within each as required.

Each Pin follows the same workflow as any other Pin — the assignee gets notified, updates their status, and marks it complete when done. Each completion drives the project's overall progress forward.

### Category Comments

Every project category has its own **comment thread**. Comments are useful for updates, coordination notes, or context that isn't tied to a specific Pin. Anyone with access to the project can post comments, and comments appear at the top of the selected category view.

### Adding a Pin to a Category During Creation

When creating a Pin and adding it to a project, you can select which category the Pin belongs to directly from the create screen. No need to add the Pin first and categorize it afterward.

## Timeline View

The **Timeline** tab is a Gantt-style view for planning and tracking work across the project's lifecycle. It sits alongside the Pins, Documents, and Chat tabs on every project page. Anyone who is a follower of the project can view it — same access model as the rest of the project page.

Timeline is available on the **web app only**, not mobile.

**What the Timeline shows:**

- Every Pin linked to the project appears as a bar on the Timeline.
- Pins are grouped by their **project category** (the same categories used to organize Pins on the Pins tab).
- Each bar's position and length is driven by the Pin's **start date** and **due date**.
- Bar **color reflects the Pin's current status**.
- A vertical line marks **today's date**.

**Interacting with the Timeline:**

| Control | What It Does |
| --- | --- |
| Category filter | Narrow the Timeline to a specific project category, or show all. |
| Zoom levels | Toggle between **All** (full project view), **Weeks**, and **Days**. |
| Today | Jump the view back to the current date. |
| Legend | Reference for what each color and shape means. |
| Drag bars toggle | When enabled, drag a Pin's bar directly on the Timeline to adjust its start and due dates. |

Clicking a Pin on the Timeline opens a detail row where start and due dates can be edited manually.

## Project Chat

Every project has its own group chat for high-level coordination across the initiative. This is separate from each Pin's own built-in chat, which handles task-specific communication.

Use the **project chat** for broad updates and coordination. Use **Pin chat** for the work itself.

Project chats also appear in the main [Chat module](/communication/chat) alongside your other conversations, filtered under the **Projects** tab. Every project you follow will surface its chat there so you don't have to open the project to reply.

## Project Log

Every action taken on a project is recorded in the project log. This includes Pin adds and removes, category changes, follower changes, status changes, document uploads, edits, and any other project activity.

- On the **web app**, the **Logs** button sits at the top right of every project page.
- On **mobile**, the log is accessible from the three-dot menu on the project.

The log is viewable by anyone who is a follower of the project.

## Setting Up a New Project

1. Go to **Projects** → tap **\+ Create Project**
2. Add a title, description, and due date
3. Create **Categories** to represent each workstream
4. Add **Pins** within each category, set due dates, and assign them to the relevant user
5. Add **followers** and upload key documents
6. Monitor the **progress bar** as key tasks get completed

<Tip>
  To add an existing Pin to a project, open the Pin → tap the ⋯ menu → **Add to Project**.
</Tip>

## Progress & Visibility

The project manager has a single view of everything open, what is on track, and what is overdue — across every department involved — without chasing anyone for a status update.

## Exporting Projects

The full Projects list view can be exported to a spreadsheet using the **Export** button at the top right of the Projects module. The export includes all relevant fields for every project in the current view.
