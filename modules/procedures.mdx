Procedures are reusable checklist templates saved to your venue. Build a checklist once — an opening walk-through, an equipment inspection, a turnover routine — and any user can pull it into a Pin or Recurring Pin without rebuilding it from scratch.

<Info>
  **Where to find Procedures:**

  - **Web app** — sidebar under **Library → Procedures**.
  - **Mobile app** — under **More → Procedures**.
</Info>

## How Procedures Work

A procedure is a saved checklist template — a title, a description, and the list of items (organized into sections, if you want). Once saved, it lives in the library and is available to everyone at the venue.

When you add a checklist to a Pin or Recurring Pin, you have two options:

- **New checklist** — build the checklist from scratch on the Pin itself.
- **Use template** — pull from any saved procedure. The template's items are copied onto the Pin.

<Info>
  Procedures are venue-wide. Any user can create a procedure, and every user can see and use every procedure — they are not scoped to a department.
</Info>

## Creating a Procedure Template

1. Open **Library → Procedures** (web) or **More → Procedures** (mobile).
2. Tap **\+ New Procedure Template**.
3. Enter a **title** and optional **description**.
4. Add **checklist items**. Organize them into collapsible **sections** if the routine is long or has distinct phases (for example, "Pre-shift," "During shift," "Closeout").
5. Save.

The procedure is now in the library and ready to be used on any Pin or Recurring Pin.

### Build a Procedure with AI ✨

You don't have to type a procedure from scratch. Tap the AI sparkle icon ✨ on the new procedure screen and choose one of three inputs:

- **Take a photo** of a physical checklist — a printed form, laminated sheet, or wall-mounted inspection card.
- **Upload a file** — PDF, Word document, spreadsheet (XLSX), CSV, or an image of an existing checklist or SOP. PIN's AI reads the file and extracts the items automatically.
- **Describe it** — enter a text description of the procedure you want (for example, "opening walk-through for the front lobby" or "monthly HVAC preventive maintenance") and the AI will generate the checklist items automatically, including sections where applicable.

PIN's AI generates the full checklist with items already filled in — fully editable. Review, adjust, and save.

<Info>
  AI procedure creation inside the Procedures module is available on **web only**.
</Info>

### Save a Checklist as a Procedure

Any checklist inside a Pin — whether built manually or generated by Snap-to-Pin — can be saved as a procedure template. Open the Pin's checklist and tap **Save as Procedure**.

Once saved, the procedure lives in the library and can be pulled into any future Pin or Recurring Pin by anyone on the platform, following the standard procedure behavior.

## Checklist Sections

Long checklists can be broken into collapsible sections. Sections work everywhere checklists do — procedures, Pins, and Recurring Pins — and keep the working view focused without losing detail.

The assignee can expand and collapse each section as they work through it, which is especially helpful for procedures that span multiple phases, zones, or shifts.

## Using a Procedure on a Pin

When creating a Pin or Recurring Pin, in the Checklist field choose **Use template** and select the procedure you want. Every item — and every section — is copied onto the Pin.

Once copied, the checklist is part of that Pin. You can add, remove, or edit items on the Pin without affecting the procedure template.

<Warning>
  Edits to a procedure template are **not retroactive**. Updating a template only affects Pins and Recurring Pin instances created _after_ the edit — existing Pins keep the checklist they were created with.
</Warning>

## Managing Procedures

From the Procedures library you can:

- **Search** for a procedure by name.
- **Filter** by Active or Archived status.
- **View details** — title, description, field count, who created it, and when it was last updated.
- **Edit** a procedure to update items, descriptions, or sections.
- **Use in New Pin** — jump straight from a procedure into creating a new Pin with that checklist pre-loaded.
- **Export** the full Procedures list to a spreadsheet using the **Export** button at the top right.

Any user can create, edit, or archive procedures.

## When to Use a Procedure vs. a One-Off Checklist

| Use a procedure when… | Use a one-off checklist when… |
| --- | --- |
| The same checklist will be used repeatedly across different Pins. | The checklist is unique to a single Pin and will not be reused. |
| Multiple users or departments need access to the same standard routine. | The work is a one-time issue or request. |
| You want a venue-wide standard for how a task is completed. | The items are specific to that one situation. |
