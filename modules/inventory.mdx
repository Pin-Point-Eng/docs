The Inventory module gives your team a way to track and manage any operational stock associated with your department — from replenishable supplies and spare parts to deployable assets and sub-equipment components. Each department manages its own inventory independently, with no visibility into other departments' stock.

## Creating Inventory Categories

Before creating inventory items, managers must ensure the relevant category exists in the system. Categories organize inventory — for example, Cleaning Supplies, Electrical Parts, or Ride Components.

Navigate to the **Inventory module on the web app** and select the category management option. Once created, the category will appear in the dropdown when adding new inventory items.

## Creating an Inventory Item

Only managers can create inventory items. Navigate to the Inventory module and tap the create button.

**Required:**

- **Name** — A clear, identifiable name for the item.
- **Department** — The department this inventory belongs to.
- **Category** — Must be created first before it appears in the dropdown.

**Optional fields:**

| Field | Details |
| --- | --- |
| Minimum Threshold | Triggers an automatic restock Pin when stock falls below this level. |
| Quantity on Hand | The current stock level when setting up the item. |
| Max on Hand | The maximum quantity to keep on hand. |
| Unit | The unit of measurement — each, box, roll, etc. |
| Cost per Unit | The cost per unit for tracking purposes. |
| Internal ID | An internal reference number for the item. |
| Physical Location | Where the item is physically stored on the property. |
| Vendor | Link this item to a [vendor profile](/modules/vendors) — replaces the old free-text Supplier field. |
| Equipment | Link this inventory to a specific piece of equipment it supports. |

<Warning>
  Set the minimum stock threshold carefully. The auto-restock Pin only fires when quantity falls below the minimum — set it too low and the team won't be alerted in time. Calibrate the threshold to leave enough buffer to restock before anything runs out.
</Warning>

## Linking an Inventory Item to a Vendor

Inventory items are linked to a real [vendor profile](/modules/vendors) rather than a free-text supplier name. Each item can be linked to **one** vendor.

From the inventory item you can see which vendor supplies it; from the vendor profile you can see every item sourced from that vendor.

## How Inventory Is Used

### Replenishable Inventory

Track consumable items like cleaning supplies, maintenance parts, or safety equipment. Set a minimum stock threshold and PIN automatically creates a restock Pin for your department when quantity falls below it — the team is alerted before anything runs out.

### Deployable Inventory

Track items that move around the property. When removing inventory, log a note indicating where it has been deployed. All deployment notes are stored in the item's notes history, giving you a running record of where things currently are.

### Sub-Equipment Tracking

Use inventory to document the individual components or parts that make up a larger piece of equipment. Rather than actively tracking quantities, this gives the team a reference for what sub-components exist within an asset.

## What's on an Inventory Page

Item name, category, unit type, cost per unit, linked [vendor](/modules/vendors), storage location, current quantity, min and max thresholds, linked equipment, related Pins, and notes history.

## Day-to-Day Usage

- Update quantity as items are used or restocked
- For deployable items, add a note indicating where it has been sent
- Link an item to a piece of equipment to surface it on the asset page
- Check linked Pins to see what's being restocked or used in repairs

## Linking Inventory to a Pin

Inventory items can be linked to a Pin the same way equipment is. Any user with permission to edit inventory can link items and log usage.

- One or more inventory items can be linked to a single Pin, from the Pin's detail page.
- When linking, the user can log the **quantity used** at that time — or update the quantity later by opening the inventory item's detail page.
- Any quantity logged on a Pin **automatically reduces the on-hand quantity** in the Inventory module.
- If the on-hand quantity drops below the minimum threshold as a result, a **restock Pin is automatically created** — the same low-stock behavior described below.
- All inventory usage from Pins is written to the item's **history**, giving a running record of where and when that item has been used.

Inventory linking works the same way on Recurring Pins as it does on regular Pins.

## Low Stock Alerts

When the quantity of any inventory item falls below its minimum threshold, PIN automatically creates a restock Pin assigned to that item's department — nothing runs out without someone being notified.

## QR Codes for Inventory

Generate printable QR codes for any inventory item so field teams can scan and open the item's detail page instantly.

**Generating codes (web only):**

1. From the Inventory list view on the web app, **bulk-select** the items you want to generate codes for.
2. Click **Actions** and choose the generate QR codes option.
3. The codes generate as a printable sheet, ready to be printed and placed on shelves, bins, or storage locations.

Each QR code is tied to the specific inventory record it was generated for and always opens that item's detail page when scanned.

**Scanning codes (mobile):**

Tap the QR scanner button at the top of the mobile app's Overview screen to open the camera. Scanning an inventory QR code jumps straight to the item's detail page.

## Exporting Inventory

The full Inventory list view can be exported to a spreadsheet using the **Export** button at the top right. The export includes all relevant fields for every inventory item in the current view.
